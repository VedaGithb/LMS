# VedaLearn — LMS платформа для обучения веб-разработке

Fullstack-приложение образовательной платформы (LMS). Включает каталог курсов, интерактивный плеер уроков с отслеживанием прогресса, личный кабинет студента и глобальные настройки интерфейса.

## Стек технологий

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, TanStack Query v5, React Router, Lucide Icons, Vite
- **Backend:** Node.js, Express, PostgreSQL, JWT, bcrypt, Zod

---

## Основной функционал

### Обучение и плеер уроков
- **Каталог и программы:** фильтрация по категориям, поиск курсов, просмотр программы и запись на курс.
- **Блочный контент урока:** поддержка теории, заголовков, сниппетов кода, списков и заметок.
- **Запоминание позиции скролла:** при чтении длинных уроков позиция сохраняется в `localStorage`, при повторном открытии страница автоматически доскролливается до места остановки.
- **Автопереход к следующему уроку:** автоматическое открытие следующего материала после отметки текущего урока пройденным.
- **Интерактивный сайдбар:** отображение всех модулей курса с отметками завершенных уроков.

### Кабинет студента и профиль
- **Страница «Мои курсы»:** сводная статистика (активные курсы, завершенные уроки, средний прогресс), карточки курсов со статусами завершения и empty state при отсутствии записей.
- **Профиль:** информация об аккаунте, сводка обучения, форма смены пароля и выход из системы.

### Настройки интерфейса (Settings Engine)
- Единый `SettingsContext` с синхронизацией в `localStorage`.
- Масштабирование размера шрифта интерфейса (16px / 18px) через базовый `fontSize` корневого элемента.
- Переключение темы оформления (светлая / темная).
- Управление поведением плеера (включение/отключение автоперехода и скролла).

## Архитектура проекта

```text
├── backend/
│   ├── src/
│   │   ├── db/          # Подключение к PostgreSQL (pg pool)
│   │   ├── middleware/  # Валидация Zod, проверка JWT
│   │   ├── routes/      # Роуты API (users, courses, modules, lessons, enrollments)
│   │   ├── schemas/     # Схемы валидации запросов
│   │   └── services/    # Бизнес-логика и SQL-запросы к БД
│
└── frontend/
    ├── src/
    │   ├── app/         # Роутер и провайдеры (React Query)
    │   ├── features/    # Модули по фичам (auth, courses, lessons, enrollments, settings)
    │   ├── pages/       # Страницы приложения
    │   ├── shared/      # Общие компоненты (Header, Layouts, ProtectedRoute)
    │   └── styles/      # Глобальные стили Tailwind v4
```

## Запуск проекта локально

### 1. Требования
- Node.js 18+
- Запущенный PostgreSQL

### 2. Бэкенд
```bash
cd backend
npm install
```

Создайте `.env` в папке `backend/`:
```env
PORT=3000
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your_password
DB_DATABASE=lms
JWT_SECRET=your_jwt_secret
```

Запуск:
```bash
npm run dev
```

### 3. Фронтенд
```bash
cd ../frontend
npm install
npm run dev
```
Фронтенд будет доступен по адресу `http://localhost:5173`.
